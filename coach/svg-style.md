# Exercise illustration style guide (plan v2.4 §4.7)

Every illustration — including exercises Claude Code adds later — must follow this guide so the library stays consistent.
Seed illustrations are generated by `scripts/svg/` (skeleton + poses); run `pnpm run svg:build` at the repo root to see how they are built, or hand-write one with the same structure.

## Frame

- `<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 320 200" role="img" aria-label="<exercise name>">`
- Background: `<rect class="bg" width="320" height="200" rx="12"/>`, floor line at `y=192`.
- **2 panels**: left x 0–150 labelled "Bắt đầu" (start), right x 160–310 labelled "Kết thúc" (end) (labels use `class="t"` at y=18), with a small triangular arrow between them. Labels stay in Vietnamese.
- Figure seen **from the side, facing right**; exercises that need both arms visible (lateral raise, pec deck, reverse fly) are drawn **from the front**.

## Strokes & colors (declared in the SVG's `<style>`)

| class | used for | light | dark |
|---|---|---|---|
| `.bd` | body (stroke 9, round) | `#2b3440` | `#d7dde4` |
| `.hd` | head (circle r=10) | `#2b3440` | `#d7dde4` |
| `.p` / `.pf` | **primary muscle group** (stroke / fill) | `#e8590c` | unchanged |
| `.s` / `.sf` | secondary muscle groups | `#f4a261` | unchanged |
| `.eq` / `.eqf` | equipment (stroke / fill) | `#9aa3ad` / `#dde2e8` | `#6b7682` / `#2d343d` |
| `.ar` + `.ah` | dashed arrow tracing the path of the joint that moves most | `#e8590c` | unchanged |

A `@media (prefers-color-scheme:dark){…}` block is required for the classes that change color.
Body segments colored by muscle group: chest/back/abs → torso; shoulders → dot at the shoulder joint; biceps/triceps → upper arm; quads/hamstrings/glutes → thigh; calves → lower leg.

## Forbidden (rejected by the validator and the DB CHECK)

- `<script>`, `on…=` attributes, `<foreignObject>`, `javascript:`, `<!ENTITY`, `@import`
- external links / images (`href`/`src` may only point to `#id`)
- larger than **15 KB** (seed illustrations are ~2–3 KB)

## Alongside the illustration

- `cues`: 3–5 short technique cues, in Vietnamese, imperative ("Ép bả vai ra sau").
- `common_mistakes`: 2–3 common mistakes, in Vietnamese.
- `reference_url` (optional): video link for the user to open — the app does not embed it.

Check: `pnpm run preview-svg <file.svg>` (previews on light + dark backgrounds).
